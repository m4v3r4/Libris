# Security Policy

## Supported Versions

Libris is a small project and does not maintain long-term support branches. Security fixes are normally made on the current release line.

| Version | Support |
| --- | --- |
| `1.2.x` | Supported |
| `1.1.x` | Best effort when practical |
| `1.0.x` and older | Not supported |

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for a suspected security vulnerability.

Use GitHub's private security advisory reporting flow instead:

https://github.com/m4v3r4/Libris/security/advisories/new

Include, when possible:

- the affected Libris version,
- the affected operating system,
- a clear description of the issue,
- reproduction steps or a minimal proof of concept,
- the potential impact,
- any suggested mitigation.

Do not include real library databases, member records, credentials, or other private data in a report unless absolutely necessary and explicitly agreed in advance.

## Response

This is a volunteer-maintained project, so no fixed response-time SLA is promised. Reports will be reviewed as time permits, with higher-impact vulnerabilities prioritized.

Please allow time for a fix before public disclosure when the issue could put users or their data at risk.
